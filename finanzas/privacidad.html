Aviso de privacidad

ALG Finanzas es una aplicación personal de un solo usuario. Su único usuario es su propio dueño.

Qué datos usa

Con permiso de solo lectura de Gmail (gmail.readonly), la app lee únicamente los avisos de compra que mandan los bancos del usuario (Banamex, Santander y Mercado Pago) para registrar sus propios gastos.

Dónde se guardan

Los datos se guardan solo en la computadora privada del usuario. No se venden, no se comparten con terceros y no se usan para publicidad. La app nunca envía, borra ni modifica correos.

Uso de datos de Google

El uso de la información recibida de las APIs de Google se apega a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo retirar el acceso

El usuario puede retirar el permiso en cualquier momento en myaccount.google.com/permissions.
